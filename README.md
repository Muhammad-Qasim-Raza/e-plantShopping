# Paradise Nursery Shopping Application

A modern React + Redux shopping cart application for **Paradise Nursery**, an online houseplant shop.

## Features

- Dark, responsive landing page
- Paradise Nursery company/about section
- 3 plant categories with 6 unique plants in each category
- Product thumbnail, name, description and price
- Add to Cart functionality
- Add-to-Cart button disables after the product is added
- Dynamic cart item count
- Redux Toolkit shopping cart state
- Increase/decrease quantity controls
- Remove individual cart items
- Dynamic item totals and total cart amount
- Checkout button with "Coming Soon" feedback
- Continue Shopping button
- Responsive layout for desktop, tablet and mobile

## Technologies

- React
- Redux Toolkit
- React Redux
- Vite
- CSS

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
```
